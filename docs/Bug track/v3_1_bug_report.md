## Детальное описание

### BUG-001: Ресурс закрыт (Session Closure)
**Суть:** В `main.py` внутри `switch_view` используется контекстный менеджер `async with _container()`. По завершении этого блока сессия БД уничтожается. Но NiceGUI компоненты живут дольше и пытаются использовать эту сессию при кликах.
**Решение:** Изменить архитектуру владения сессией в UI. Сессия должна открываться при каждом действии (Event Handler) или храниться в долгоживущем контейнере страницы.

### BUG-002: Потеря данных инцидента
**Суть:** Метод `report_material_incident` добавляет запись в лог, но не фиксирует транзакцию.
**Решение:** Добавить `self.db_session.commit()`.

### BUG-003: Зомби-таймеры
**Суть:** `ui.timer(15.0)` в `WarehouseView` продолжает тикать в фоне, даже если пользователь ушел на Dashboard.
**Решение:** Использовать привязку таймера к элементу или ручную остановку через `timer.deactivate()`.

### BUG-004: Мертвый код SessionContext
**Суть:** Класс объявлен, но Omnibar и фильтры его игнорируют. При переходе из поиска фильтр не применяется к таблице.
**Решение:** Внедрить вызовы `SessionContext.set` в `MainLayout` и `get` в соответствующих View.
