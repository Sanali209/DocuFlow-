## 🔧 Refactoring Plan

### Цели
- **Стабилизация кода**
- **Минимизация дубликации** (логики, компонентов)
- **Улучшение архитектуры** NiceGUI (агенты путаются в ней)
- **Минимизация будущих ошибок**

### Направления

#### 1. Вынести UI компоненты в `lib/widgets/`
- Создать `lib/ui/` с переиспользуемыми компонентами
- Убрать `.classes("text-slate-500 text-sm")` в пользу CSS классов или theme констант
- Примеры: кнопки, карточки, баджы, формы

#### 2. Создать UI kit / Design Tokens
- Единые константы для цветов, отступов, шрифтов
- Темплейты для карточек, таблиц, модалок
- Централизованные стили в `core/layout.py`

#### 3. Абстракция View
- Вынести `MainLayout` в отдельный модуль
- Унифицировать паттерн `render()` для всех Views
- Документировать структуру view файлов

#### 4. Убрать дублирующуюся логику
- Поиск: `core/search.py` + дубликаты в `folder_scanner/`
- Статусы: разные enum в `domain/entities/` и `features/`
- Timer management: разбросано по view файлам
