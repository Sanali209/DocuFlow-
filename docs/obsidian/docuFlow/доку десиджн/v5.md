## A. Контекст цеха (из канваса)

**Цех металлообработки.** Рабочие места — лазеры по резке металла + компьютер начальника.
**Работа ведётся в 2 смены.** Основной продукт — детали для автобусов (Apollo и др.).

**Как работает сейчас (без системы):**
- Приходит **печатный наряд (Сидра)** — бумага с названием, датой, списком нестов
- Раскройщик присылает **папку** на сетевом диске с тем же именем + GNC файлы
- Бригадир распределяет батчи, сверяет материалы, расставляет приоритеты
- Выполненный пункт **обводится кружком** на бумаге — никакой системы!
- Готовые детали складируют — никто не знает где они лежат
- Может прийти **письмо** (Mihtav) — внеплановый заказ, такая же структура
- Оператор может сам **создать наряд** (Rework) когда обнаружил брак
- Прецеденты: папка есть — нестов нет; документ получен — папки нет

## B. Операционный цикл (8 этапов)

```
┌── 1. ПОЛУЧЕНИЕ РАБОТЫ ──────────────────────────────────────────┐
│  Сканер → находит папку → WorkItem создан (статус: FOLDER_NO_DOC)
│  Бригадир → подтверждает получение бумажного наряда →           │
│             статус: REGISTERED + doc_received_at stamp          │
│  Оповещение (chat/уведомление): "Новый наряд SIDRA-353203"     │
├── 2. ПОДГОТОВКА К РАБОТЕ ───────────────────────────────────────┤
│  Бригадир: проверяет наличие материалов → Reservation           │
│  Бригадир: если материала нет → дозаказ (CommentThread "order") │
│  Батчинг: группировка TaskItem по материалу/толщине/размеру     │
│  Бригадир: комментирует батчи, выставляет приоритеты           │
│  Проверка запаса: "Деталь 3433-11-004-G уже есть в запасе!"    │
│  Если есть запас: экспорт задачи переделки в службу нестов,    │
│  блокировка батча до переимпорта обновлённых GNC               │
│  Учёт расходников: сопла, линзы, клейкая лента (Consumable)    │
├── 3. ПРИЁМ В РАБОТУ (ОПЕРАТОР) ────────────────────────────────┤
│  Оператор видит доступные батчи → редактирует → резервирует    │
│  WorkerBucket: иерархия Batch[] → TaskItem[]                   │
│  FileBus REQ: lock_batch → Мастер подтверждает                 │
│  Статус TaskItem → IN_PROGRESS                                  │
├── 4. ВЫПОЛНЕНИЕ / МОНИТОРИНГ ──────────────────────────────────┤
│  Оператор: старт/стоп, паузы с причинами → WorkLog             │
│  Инциденты: лазер сломался, деталь не вышла → IncidentLog      │
│  Шаблоны предупреждений: для известных проблемных деталей      │
│  Бригадир: дашборд всех активных лазеров (real-time)           │
│  Начальник: KPI дашборд (выработка, простои, эффективность)    │
│  Чат: привязан к ProjectThread / WorkItemThread / TaskThread    │
├── 5. ЗАВЕРШЕНИЕ И УЧЁТ ─────────────────────────────────────────┤
│  TaskItem → DONE → диалог "Куда кладём?"                       │
│    Вариант A: Новая паллета → ProductionUnit с label_id        │
│    Вариант B: К существующей паллете → сканируем QR            │
│  MaterialStock: фактическое списание = MaterialAudit           │
├── 6. СКЛАДИРОВАНИЕ ГОТОВОЙ ПРОДУКЦИИ ──────────────────────────┤
│  ProductionUnit → StorageLocation (стеллаж/контейнер)          │
│  Label: человекочитаемый ID (напр. "2025-07-А-042")            │
│  Кладовщик: поиск "где детали из SIDRA-353203?"                │
│  Обратный поиск: "деталь 3433-11-004-G → паллета → стеллаж"   │
│  Перевод в запас: ProductionUnit.is_stock = True               │
├── 7. РЕТРОСПЕКТИВНЫЙ ПОИСК ────────────────────────────────────┤
│  PartLibrary: поиск по SKU / материалу / bbox±допуск /         │
│               кол-ву отверстий / тексту комментариев           │
│  Прямой: "Деталь X в наряде Y?" → TaskPart → TaskItem         │
│  Обратный: "Где деталь X?" → все ProjectWorkItem → паллеты    │
│  Поиск с частичным совпадением по всем значимым полям          │
├── 8. УПРАВЛЕНИЕ СКЛАДОМ МАТЕРИАЛОВ ────────────────────────────┤
│  MaterialStock: приход / списание / инвентаризация             │
│  Расходники: Consumable (сопла, линзы, лента)                  │
│  MaterialAudit: кто/когда/сколько/на основании чего            │
│  Передача смены: WorkerBucket handover с аннотациями           │
└─────────────────────────────────────────────────────────────────┘
```

## D. Полный список доменных сущностей

### D1. Производственная иерархия

```
Project (Контейнер: "20 автобусов Apollo", "Default")
  └── WorkItem[]  (Сидра / Письмо / Доработка)
        └── TaskItem[]  (Один GNC файл)
              └── TaskPart[]    (Артикул детали + qty)
                    └── PartLibrary  (Справочник: SKU → bbox, svg, метрики)

MaterialType  (Библиотека: "AA 5052-H32 + 3mm + 3250x1250")
  └── MaterialStock[]  (Конкретная пачка на складе)
        ├── Reservation[]   (Soft/Hard резерв под WorkItem)
        └── MaterialAudit[] (Движения: приход/списание/корректировка)

TaskItem → ProductionUnit[] (Паллета с готовыми деталями)
  └── StorageLocation  (Физическое место: "A-02-3")

WorkerBucket  (Корзина оператора: узел → [{Batch, TaskItem[]}])
WorkLog       (Журнал трассировки: все события)
ChatMessage   (Оперативный чат, привязанный к объекту)
Tag           (Теги: "Срочно", "Внимание", "Брак")
Consumable    (Расходники: сопла, линзы, лента)
ConsumableLog (Учёт расхода/пополнения расходников)
PartTemplate  (Шаблон предупреждений для проблемных деталей)
IncidentLog   (Инциденты: поломка лазера, брак детали)
```

# --- PROJECT ---------------------------------------------------
class Project(BaseEntity, table=True):
    name: str = Field(unique=True, index=True)
    description: Optional[str] = None
    is_default: bool = Field(default=False)   # "Default" всегда существует
    deadline: Optional[date] = None
    status: str = Field(default="active")     # active|completed|archived
    # Relations
    work_items: List["WorkItem"] = Relationship(back_populates="project")
    tags: List["Tag"] = Relationship(back_populates="project")  # через link table
    comments: List["ChatMessage"] = Relationship(
        sa_relationship_kwargs={"primaryjoin": "ChatMessage.ref_project_id == Project.id"}

# --- WORK ITEM ------------------------------------------------
class WorkItemType(str, Enum):
    SIDRA  = "sidra"
    MIHTAV = "mihtav"
    REWORK = "rework"

class WorkItemStatus(str, Enum):
    NEW            = "new"
    FOLDER_NO_DOC  = "folder_no_doc"   # Папка найдена, нет бумажного наряда
    DOC_NO_FOLDER  = "doc_no_folder"   # Наряд зарегистрирован, папки нет
    REGISTERED     = "registered"      # Папка + документ подтверждены
    IN_PROGRESS    = "in_progress"
    ON_HOLD        = "on_hold"
    DONE           = "done"
    ARCHIVED       = "archived"

class WorkItem(BaseEntity, table=True):
    project_id: int = Field(foreign_key="project.id", index=True)
    work_item_type: WorkItemType
    status: WorkItemStatus = WorkItemStatus.NEW
    # Идентификация (ключ идемпотентности для сканера)
    folder_name: str = Field(unique=True, index=True)
    folder_path: str              # Относительный от scan_root
    # Только для SIDRA
    sidra_number: Optional[str] = None   # "353203"
    sidra_step: Optional[str] = None     # "SHLAV-2" (шаг наряда)
    # Временны́е метки
    folder_found_at: datetime = Field(default_factory=datetime.now)
    doc_received_at: Optional[datetime] = None   # Бригадир регистрирует вручную
    started_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None
    last_scanned_at: Optional[datetime] = None
    # Relations
    project: Optional[Project] = Relationship(back_populates="work_items")
    task_items: List["TaskItem"] = Relationship(back_populates="work_item")
    logs: List["WorkLog"] = Relationship(back_populates="work_item")
    reservations: List["Reservation"] = Relationship(back_populates="work_item")


# --- TASK ITEM (бывший Nest) ----------------------------------
class TaskItemStatus(str, Enum):
    PLANNED     = "planned"
    IN_PROGRESS = "in_progress"
    ON_HOLD     = "on_hold"
    DONE        = "done"
    CANCELLED   = "cancelled"
    BLOCKED     = "blocked"     # Заблокирован (ждёт переделки нестов)

class TaskItem(BaseEntity, table=True):
    work_item_id: int = Field(foreign_key="workitem.id", index=True)
    mat_type_id: Optional[int] = Field(default=None, foreign_key="materialtype.id")
    status: TaskItemStatus = TaskItemStatus.PLANNED
    priority: int = Field(default=0)       # 0=normal, 1=high, 2=critical
    is_urgent: bool = Field(default=False)
    # Файл (буквонезависимый)
    file_name: str
    file_path: str    # ОТНОСИТЕЛЬНЫЙ от scan_root
    file_hash: str    # MD5 — детектор изменений → уведомление
    # Из *SHEET в GNC
    sheet_x: Optional[float] = None
    sheet_y: Optional[float] = None
    sheet_qty: Optional[int] = None
    thickness: Optional[float] = None
    # Из имени файла
    step_index: Optional[int] = None
    batch_index: Optional[int] = None
    # Назначение и хронология
    assigned_to_node: Optional[str] = None
    scanned_at: datetime = Field(default_factory=datetime.now)
    gnc_date: Optional[datetime] = None   # Дата из GNC (DATE JUL 07 2025)
    started_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None
    # Relations
    work_item: Optional[WorkItem] = Relationship(back_populates="task_items")
    mat_type: Optional["MaterialType"] = Relationship()
    task_parts: List["TaskPart"] = Relationship(back_populates="task_item")
    production_units: List["ProductionUnit"] = Relationship(back_populates="task_item")
    logs: List["WorkLog"] = Relationship(back_populates="task_item")


class TaskPart(BaseEntity, table=True):
    """Деталь в конкретном TaskItem с количеством."""
    task_item_id: int = Field(foreign_key="taskitem.id", index=True)
    part_sku: str = Field(foreign_key="partlibrary.sku", index=True)
    version: str = Field(default="A")   # "G" в "3433-11-004-G"
    qty: int = Field(default=1)
    task_item: Optional[TaskItem] = Relationship(back_populates="task_parts")
    part: Optional["PartLibrary"] = Relationship(back_populates="task_parts")


# --- PART LIBRARY ----------------------------------------------
class PartLibrary(BaseEntity, table=True):
    """Глобальный справочник деталей. Пополняется сканером."""
    sku: str = Field(primary_key=True, index=True)   # "3433-11-004-G"
    mat_type_id: Optional[int] = Field(default=None, foreign_key="materialtype.id")
    name: Optional[str] = None
    # Габариты из SVGGenerator.calculate_bounds() + generate_thumbnail() → (data_w, data_h)
    bbox_x: Optional[float] = None   # Реальная ширина детали из G-кода контуров (мм)
    bbox_y: Optional[float] = None   # Реальная высота (мм)
    # Метрики из GNCParser
    contour_count: int = Field(default=0)
    corner_count: int = Field(default=0)
    hole_count: int = Field(default=0)   # Внутренние контуры = отверстия
    weight_per_pcs: Optional[float] = None   # кг
    # SVG превью (из SVGGenerator MVP — УМЕЕТ считать bbox и рисовать контур)
    svg_preview_path: Optional[str] = None
    # Аудит
    first_seen_at: datetime = Field(default_factory=datetime.now)
    last_seen_at: datetime = Field(default_factory=datetime.now)
    task_parts: List[TaskPart] = Relationship(back_populates="part")
    # Шаблоны предупреждений (проблемные детали)
    templates: List["PartTemplate"] = Relationship(back_populates="part")


class PartTemplate(BaseEntity, table=True):
    """Шаблон предупреждения для проблемной детали."""
    part_sku: str = Field(foreign_key="partlibrary.sku", index=True)
    message: str          # "Деталь задевает голову лазера — ОСТОРОЖНО!"
    severity: str         # info | warning | critical
    created_by: str
    part: Optional[PartLibrary] = Relationship(back_populates="templates")


# --- MATERIALS -------------------------------------------------
class MaterialFormFactor(str, Enum):

class MaterialType(BaseEntity, table=True):

## E. SVGGenerator — умеет считать bbox ✅

Проверено: `SVGGenerator.calculate_bounds(part)` → `(min_x, min_y, max_x, max_y)`
и `generate_thumbnail(part, path)` → возвращает `(data_w, data_h)` — **реальные мм детали**.

```python
# При сканировании GNC → PartLibrary:
svg_gen = SVGGenerator()
data_w, data_h = svg_gen.generate_thumbnail(
    part=gnc_sheet.parts[0],
    output_path=f"previews/{sku}.svg"
)
part_lib.bbox_x = data_w   # Реальная ширина из G-кода (мм)
part_lib.bbox_y = data_h   # Реальная высота из G-кода (мм)
```

Используется для:
- `PartLibrary.bbox_x/y` (точный bbox из контуров, не из PART SIZE)
- Поиск с допуском: `WHERE bbox_x BETWEEN :x-tol AND :x+tol`
- SVG превью в UI

## F. Человекочитаемые ID паллет

```
Формат: {YEAR}-{MONTH}-{NODE_CODE}-{SEQ:03d}
Пример: "2025-07-А-042"

YEAR   = 2025
MONTH  = 07
NODE   = "А" (буква лазера, из Workplace.node_id → display code)
SEQ    = 042 (сквозная нумерация на этом узле за месяц)
```

**ProductionUnit — объединение / разделение:**
- `merge(unit_a, unit_b)` → новый `label_id`, списывает оба
- `split(unit, qty)` → два новых unit с распределёнными qty
