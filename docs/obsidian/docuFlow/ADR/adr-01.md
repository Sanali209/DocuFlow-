## adr-01


- Унифицированное SDK (DocuFlow): проект переориентирован на создание общего SDK, без привязки к конкретному производству.

- BaseSystem: архитектура доступа к «холодной» конфигурации (self.config) и «горячим» настройкам из БД (self.settings).

- Асинхронность: все системы и методы — async по умолчанию.

- Rich-логирование: интеграция loguru с RichHandler для красивого и информативного вывода.
